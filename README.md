# PLNAR Claims Workspace — Product Vision

Interactive product concept showing a restoration claim workflow from field capture through claim package and tracking.

## Flow
Capture → Build → Validate → Compare → Resolve → Package → Track

## Important
- Synthetic demonstration claim only.
- This prototype intentionally mixes current product concepts with proposed and experimental workflows.
- It is not a statement that all demonstrated functionality exists in production.
- The concept deliberately stops short of claimant representation, negotiation, or settlement.

## Run
```
npm install
npm run dev
```

Designed for deployment on Vercel as a standalone Next.js concept application.
